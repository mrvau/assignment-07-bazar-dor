# বাজার দর · BazarDor

**আজকের বাজারের দাম এক নজরে।**

BazarDor is a market price guide for everyday essentials in Bangladesh. It brings product prices, daily price changes, and market-by-market comparisons together in one place.

## Technologies

- **Next.js 16** — App Router and server-rendered pages
- **React 19** and **TypeScript**
- **Tailwind CSS 4** — styling
- **HeroUI** — interface components
- **Better Auth** and **MongoDB** — authentication and session storage
- **Iconify** and **Lucide** — icons

## Key features

1. **Daily price overview** — browse essential products and see which prices have risen or fallen.
2. **Category browsing and sorting** — explore products by category and sort category listings by price.
3. **Product price breakdowns** — view price changes alongside the lowest, highest, and average prices across markets.
4. **Market comparisons** — compare minimum and maximum prices by market and division.
5. **Account access** — sign up or sign in with email and password, Google, or GitHub to access product details and a personal profile.
